# VynOps

VynOps builds open-source tools for operating modern infrastructure with more
clarity and less toil.

Our projects bring observability, incident response, automation, cost
intelligence, security, data operations, and delivery workflows into focused
tools for platform and operations teams.

## Projects

- **VynOps** - Kubernetes operations and AIOps platform
- **VynAI** - AI gateway and Ollama fleet management
- **VynCost** - Cloud cost visibility and optimization
- **VynDB** - Database operations and administration
- **VynDC** - Data center management
- **VynCICD** - CI/CD pipeline management

## Principles

- Self-hosted and designed for operational control
- Built around the tools teams already use
- Practical automation with clear audit trails
- Open source where transparency matters
